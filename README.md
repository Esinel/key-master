
  KeyMaster — click anything with your keyboard. Press Option+Shift+M to label every clickable element on screen. Type the hint to click — no mouse needed.

  Features:
  • Works on every page, zero configuration
  • Short, easy-to-type key hints
  • Smart multi-character hints for pages with many links
  • Visual feedback as you type
  • Press Escape to dismiss

  ---
  Privacy Policy (PRIVACY.md):

  # Privacy Policy

  KeyMaster does not collect, store, transmit, or share any user data.

  All functionality runs entirely within your browser. No analytics, no tracking, no network requests.

  ## Permissions

  The extension requires access to all URLs solely to inject the hint overlay on any webpage you activate it on. No page content is read, recorded, or sent anywhere.
